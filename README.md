# Vercel Stress Test Tool

## About
HTTP stress testing tool optimized for Vercel serverless environment.

## Usage
Visit: `https://your-app.vercel.app/api?target=https://example.com&concurrency=10&duration=5`

### Parameters:
- `target` - Target URL (default: https://167.104.100.205/)
- `concurrency` - Number of workers (default: 10)
- `duration` - Test duration in seconds (default: 5)
